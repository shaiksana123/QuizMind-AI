# QuizMind AI 🤖
### AI-Powered Quiz Generator

## About the Project

QuizMind AI is designed to make learning and self-assessment easier using Artificial Intelligence.

It transforms study materials into interactive quizzes using Google Gemini AI. Users can enter text or upload documents to generate questions based on their learning needs.

## ✨ Features

- Generate quizzes from text, PDF, DOCX and TXT files.
- Customize the number of questions (1–100).
- Choose Easy, Medium or Hard difficulty.
- Supports MCQs and True/False questions.
- Navigate questions and track selected answers.
- View scores, correct answers and explanations.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **AI Integration:** Google Gemini API

## 📚 Challenges & Learning

During development, I worked on integrating the Gemini API, handling different document formats and connecting the frontend with the backend.

This project helped me gain practical experience in full-stack development, API integration, file processing and building AI-powered applications.

## 🚀 Run Locally

**1. Clone the repository**
```bash
git clone https://github.com/shaiksana123/QuizMind-AI.git
```

**2. Install backend dependencies**
```bash
cd QuizMind-AI/backend
npm install
```

**3. Configure the API key**

Create a `.env` file inside the `backend` folder and add your Gemini API key using the environment variable name expected by the application.

**4. Start the backend**
```bash
node server.js
```

**5. Run the frontend**

Open `frontend/index.html` using the VS Code Live Server extension.
